# Incident 2026-08-14: gateway worker pool exhaustion

SEV-2 with 41 minutes of degraded checkout on the [[payment-gateway]]. [src:0a594426ef94]
One slow acquirer held workers up to the timeout and filled the pool, so healthy acquirers became unreachable. [src:0a594426ef94]
Root cause: the EU cluster still ran the 30 s timeout that [[request-timeouts]] describes as superseded. [src:0a594426ef94]

## Action items

- Roll out the 12 s timeout to every cluster, done 2026-08-15. [src:0a594426ef94]
- Alert on worker pool saturation above 80 %. [src:0a594426ef94]
